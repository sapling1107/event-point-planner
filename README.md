# Event Point Planner

Event Point Planner 是一款用於規劃手遊活動 Point 進度的本機網頁工具。

輸入活動期間、目標 Point 與目前累計進度後，工具會自動計算：

- 活動總日數
- 剩餘日數
- 尚欠 Point
- 每日最低需求
- 目前進度百分比
- 相對原始計畫的超前或落後
- 依最新實際進度重新分配的未來每日計畫

所有資料預設只儲存在目前瀏覽器中，不需要登入，也不會上傳至伺服器。

---

## 功能概覽

### 多活動管理

可以同時建立多個手遊活動。

每個活動可獨立保存：

- 手遊名稱
- 活動名稱
- 活動開始日期
- 活動結束日期
- 目標 Point
- 進度歷史
- 自訂刷取期間
- 最新進度與未來計畫

活動列表預設保持收合，點擊活動卡即可展開詳細資料。再次點擊同一張活動卡會將其收起。

### 手遊名稱管理

可以先建立常用手遊名稱，再於新增活動時從清單中選擇。

移除手遊名稱時：

- 只會從可選清單移除
- 不會刪除既有活動
- 已使用該名稱的活動仍會保留原本資料

### 自訂計畫日期

預設情況下，刷取計畫期間會與活動期間相同。

開啟「自訂計畫日期」後，可以另外設定：

- 開始刷取日期
- 希望完成日期

適合以下情況：

- 活動開始後幾天才開始刷
- 希望提早完成
- 不打算使用完整活動期間
- 活動期間內有幾天無法遊玩

自訂計畫日期必須位於活動期間內。

## 建立活動

建立活動時，需要輸入：

- 手遊名稱
- 活動名稱
- 活動開始日期
- 活動結束日期
- 目標 Point
- 進度截至日期
- 截至該日累計 Point

建立時輸入的進度資料，會直接成為該活動的第一筆進度歷史。

例如：

    進度截至日期：2026-08-02
    截至該日累計：1,000 Point

會保存為：

    2026-08-02：1,000 Point

即使目前 Point 為 0，也會建立一筆正式進度紀錄。

---

## 每日計畫

工具會先建立一份原始計畫，將目標 Point 平均分配到整個計畫期間。

例如：

    目標 Point：100,000
    計畫日數：10 日

原始計畫約為每日 10,000 Point。

當 Point 無法整除日數時，工具會使用整數平均分配：

- 不使用小數
- 每日差距最多 1 Point
- 最後一天精確到達目標 Point

---

## 動態調整未來計畫

每次更新實際進度後，工具會保留原始計畫作為比較基準，並重新分配未來尚欠的 Point。

例如：

    目標：100,000 Point
    計畫：10 日
    第 4 日實際累計：30,000 Point

原始第 4 日目標為 40,000 Point，因此目前落後 10,000 Point。

工具會將尚欠的 70,000 Point，重新平均分配至剩餘 6 日。

因此：

- 原始計畫仍用於判斷超前或落後
- 未來每日計畫會依實際進度調整
- 最後一天仍會精確到達目標

若已達成或超過目標，未來每日新增 Point 會變為 0，累計值不會倒退。

---

## 進度歷史

每次更新進度時，工具都會保存一筆歷史紀錄，而不是只保留最新數字。

例如：

    2026-08-01：1,000 Point
    2026-08-02：20,000 Point
    2026-08-03：45,000 Point

每日計畫會分別顯示：

- `實際紀錄`：過去保存的進度
- `最新進度`：日期最晚的一筆紀錄
- `未記錄`：沒有輸入資料的過去日期
- 最新進度後：重新計算的未來計畫

### 同日修正

若再次輸入同一天的進度，會覆蓋該日期原本的紀錄，不會新增重複項目。

例如：

    原本：
    2026-08-02：20,000 Point

    修正後：
    2026-08-02：22,000 Point

進度歷史仍只有一筆 2026-08-02。

### 補記較早日期

可以補記較早日期的進度。

例如目前已有：

    2026-08-03：45,000 Point

之後補記：

    2026-08-01：5,000 Point

歷史會自動按日期排序。

活動目前進度、每日最低需求及未來計畫，仍會以日期最晚的紀錄作為基準，不會因補記舊資料而倒退。

### 累計 Point 不可倒退

由於輸入的是「截至該日累計 Point」，日期較後的紀錄不可低於日期較早的紀錄。

例如：

    2026-08-02：20,000 Point
    2026-08-03：10,000 Point

此資料不合法，工具會拒絕儲存。

補記中間日期時，也必須符合：

    較早日期 Point
    ≤ 本次輸入 Point
    ≤ 較晚日期 Point

---

## 快速更新進度

展開活動後，可以使用「快速更新進度」功能，只修改：

- 進度截至日期
- 截至該日累計 Point

不需要開啟完整活動編輯畫面。

快速更新支援：

- 新增新日期
- 修正同一天
- 補記較早日期
- 自動更新最新進度
- 立即重新計算未來每日計畫

若輸入資料與前後紀錄衝突，工具會顯示錯誤並保留原資料。

---

## 修改活動

完整修改活動時，可以更新：

- 手遊名稱
- 活動名稱
- 活動期間
- 自訂計畫期間
- 目標 Point
- 進度日期與 Point

若沒有修改進度欄位，既有進度歷史會完整保留。

若修改進度欄位：

- 同一天會覆蓋原紀錄
- 不同日期會新增或修正該日期
- 不會自動刪除原本的進度歷史
- 最新進度仍以日期最晚的紀錄為準

活動結束日期不可早於既有進度紀錄。

---

## 超前與落後

工具會使用原始計畫計算目前相對進度。

可能顯示：

    超前 5,000 Point
    落後 10,000 Point
    符合計畫
    計畫尚未開始，不比較
    計畫完成日已過，尚欠 20,000 Point

即使未來計畫已重新分配，超前或落後仍會與最初計畫比較，不會因重新計算而自動歸零。

---

## 資料儲存

所有活動與設定都儲存在目前瀏覽器的 `localStorage`。

資料不會自動同步到：

- 其他瀏覽器
- 其他裝置
- 無痕模式
- 清除網站資料後的新環境

以下操作可能造成資料消失：

- 清除瀏覽器網站資料
- 清除 localStorage
- 使用無痕／私人瀏覽模式
- 更換瀏覽器
- 更換裝置
- 重新安裝或重設瀏覽器

建議定期使用備份功能匯出資料。

---

## 備份與還原

工具支援完整備份：

- 所有活動
- 所有進度歷史
- 手遊名稱清單
- 目前選取狀態
- 自訂計畫期間

### 匯出備份

點擊「備份資料」後選擇匯出，會下載 JSON 備份檔。

檔名格式：

    event-point-planner-backup-YYYY-MM-DD-HHMMSS.json

### 匯入備份

匯入前，工具會先驗證：

- 備份格式
- 資料版本
- 活動欄位
- 進度歷史
- 日期排序
- 重複日期
- 累計 Point 是否倒退
- 最新進度快取是否一致
- 手遊名稱格式

匯入會覆蓋目前所有活動與手遊名稱清單。

匯入前請先確認目前資料已另行備份。

### 舊備份相容

目前工具可接受合法的舊版 v3 活動備份。

匯入時，舊資料中的：

    progressDate
    currentPoint

會自動轉成第一筆進度歷史。

備份外層版本仍維持：

    backupVersion: 1

## PWA 安裝

Event Point Planner 支援安裝為 PWA。

安裝後可以像一般 App 一樣：

- 從主畫面或應用程式列表開啟
- 使用獨立視窗
- 離線載入
- 保留本機活動資料

### iPhone／iPad

使用 Safari 開啟網站後：

1. 點擊分享按鈕
2. 選擇「加入主畫面」
3. 確認名稱
4. 點擊「加入」

### Android

使用 Chrome 開啟網站後：

1. 點擊瀏覽器選單
2. 選擇「安裝應用程式」或「加入主畫面」
3. 完成安裝

### 電腦

Chrome、Edge 等支援 PWA 的瀏覽器，通常會在網址列或選單中顯示安裝選項。

## 離線使用

首次成功載入後，主要 App 檔案會保存在瀏覽器快取中。

之後即使沒有網路，仍可：

- 開啟工具
- 查看活動
- 更新進度
- 新增或修改活動
- 匯出備份

資料仍保存於本機瀏覽器。

首次開啟網站時仍需要網路，以便下載 App 檔案。

## 計算規則

### 活動日數

活動及計畫日數均包含開始日與結束日。

例如：

    開始日期：8 月 1 日
    結束日期：8 月 3 日

總日數為 3 日。

### 剩餘日數

進度日期代表：

> 截至該日結束時的累計進度

因此，剩餘日數不包含進度日期本身。

例如：

    進度截至日期：8 月 3 日
    計畫完成日期：8 月 10 日

剩餘日數為 7 日。

### 每日最低需求

計算方式：

    尚欠 Point ÷ 剩餘日數

結果向上取整。

若已達成目標：

    每日最低需求 = 0 Point

若計畫日期已結束但仍未達標：

    每日最低需求 = 無剩餘日

### 未來每日分配

未來每日 Point 使用整數分配：

- 每日差距最多 1 Point
- 不產生小數
- 餘數分散至不同日期
- 最後一天精確到達目標

## 使用限制

目前版本尚未提供：

- 雲端同步
- 帳號登入
- 多裝置同步
- 進度歷史獨立管理頁
- 刪除單筆進度歷史
- 圖表分析
- 通知提醒
- 自動讀取遊戲資料
- 自動更新活動進度

目前的進度歷史只能透過：

- 快速更新進度
- 完整修改活動

進行新增或修正。

## 隱私

Event Point Planner 不需要帳號，也不會主動將資料傳送至外部伺服器。

活動資料、進度歷史與手遊清單只保存在使用者目前的瀏覽器中。
