# Event Point Planner

一個專為手機遊戲活動設計的 Point 規劃工具。

輸入活動期間、目標 Point 與目前進度後，Event Point Planner 會自動計算每日累計目標、剩餘 Point，以及接下來每天最低需要取得的 Point。

所有資料只儲存在目前裝置的瀏覽器內，不需要註冊帳號，也不會上傳到伺服器。

## 立即使用

[開啟 Event Point Planner](https://sapling1107.github.io/event-point-planner/)

## 主要功能

- 同時管理多個遊戲活動
- 自訂遊戲名稱清單
- 設定活動開始與結束日期
- 設定目標 Point 與目前累計 Point
- 自訂實際刷取開始日期與希望完成日期
- 自動產生每日累計 Point 計畫
- 顯示目前進度百分比
- 顯示剩餘 Point 與剩餘日數
- 計算接下來每日最低需要取得的 Point
- 顯示目前進度是超前、符合或落後計畫
- 快速更新活動進度
- 匯出及匯入 JSON 備份
- 支援安裝成 PWA
- 完成首次載入後可離線使用

## 基本使用方式

### 1. 新增手遊

首次使用時，先按下「管理手遊」，加入需要追蹤的遊戲名稱。

之後新增活動時，就可以直接從清單選擇遊戲。

從手遊清單移除名稱不會刪除既有活動。

### 2. 新增活動

按下「新增活動」，填寫：

- 遊戲名稱
- 活動名稱
- 活動開始日期
- 活動結束日期
- 目標 Point
- 進度截至日期
- 截至該日的累計 Point

完成後按下「新增活動」。

### 3. 自訂計畫日期

一般情況下，每日計畫會使用完整活動期間。

開啟「自訂計畫日期」後，可以另外指定：

- 開始刷取日期
- 希望完成日期

例如活動已經開始數天，或希望提早完成時，就可以只針對實際刷取期間安排每日目標。

### 4. 查看活動詳情

頁面開啟時，所有活動預設為收合狀態。

點擊活動卡後，會展開：

- 活動期間
- 刷取期間
- 剩餘日數
- 目前累計 Point
- 目標 Point
- 尚欠 Point
- 相對計畫進度

同時，下方會顯示該活動的完整每日計畫。

再次點擊同一個活動即可收起。

### 5. 更新進度

展開活動後，按下右下角的「更新進度」。

只需更新：

- 進度截至日期
- 截至該日累計 Point

儲存後，工具會重新計算剩餘 Point、每日最低需求及相對計畫進度。

## 每日計畫的計算方式

Event Point Planner 會把目標 Point 平均分配到計畫期間。

當 Point 無法完全平均分配時，每日差距最多為 1 Point，並確保最後一天的累計數字等於完整目標。

「每日最低需求」則會根據以下資料重新計算：

- 目標 Point
- 目前累計 Point
- 進度截至日期
- 剩餘計畫日數

因此，更新實際進度後，未來每天需要取得的 Point 也會同步調整。

## 安裝成 App

Event Point Planner 支援 PWA，可以安裝到手機或電腦，並以接近一般 App 的方式開啟。

### Android／支援安裝的桌面瀏覽器

開啟網站後，使用瀏覽器選單中的「安裝應用程式」、「安裝」或「新增至主畫面」。

### iPhone／iPad

使用 Safari 開啟網站後：

1. 按下分享按鈕
2. 選擇「加入主畫面」
3. 確認名稱並加入

完成首次線上載入後，安裝版可在沒有網路時繼續使用主要功能。

## 資料儲存

所有活動與手遊名稱只會儲存在目前瀏覽器的本機儲存空間。

資料不會：

- 上傳至伺服器
- 傳送給第三方
- 跨裝置自動同步
- 自動建立雲端備份

以下情況可能導致資料無法在另一環境中出現：

- 更換瀏覽器
- 更換裝置
- 使用不同網址或網域
- 清除瀏覽器網站資料
- 使用私密瀏覽模式
- 移除 App 時同時刪除網站資料
- 安裝版與原瀏覽器使用不同的資料容器

因此，重要資料請定期匯出備份。

## 備份與還原

按下「備份資料」即可使用備份功能。

### 匯出備份

按下「匯出備份」，工具會下載一個 JSON 檔案，其中包含：

- 所有活動
- 手遊名稱清單
- 目前支援的資料格式版本

建議在以下情況先匯出備份：

- 安裝成 PWA 前
- 更換裝置前
- 更換瀏覽器前
- 清除網站資料前
- 匯入其他備份前

### 匯入備份

選擇先前匯出的 JSON 檔案。

檔案通過驗證後，工具會顯示：

- 備份時間
- 活動數量
- 手遊數量
- 備份格式版本

按下「匯入並覆蓋」後，目前所有活動與手遊清單都會被備份內容取代。

匯入前建議先匯出目前資料。

## 離線使用

首次在線開啟網站後，Event Point Planner 會儲存必要的程式檔案。

之後即使沒有網路，仍可使用：

- 查看活動
- 新增、修改及刪除活動
- 更新進度
- 管理手遊名稱
- 查看每日計畫
- 匯出備份
- 匯入備份

首次從未載入過網站的裝置仍需要先連線一次。

## 隱私

Event Point Planner 是純前端工具。

它沒有：

- 使用者帳號
- 廣告
- 分析追蹤
- 後端資料庫
- 雲端同步
- 第三方登入

輸入的遊戲名稱、活動名稱、日期與 Point 都只保留在目前裝置的瀏覽器內。

## 已知限制

- 資料不會自動在不同裝置之間同步
- 清除網站資料可能刪除所有活動
- 不同瀏覽器之間不會自動共用資料
- 瀏覽器頁面與安裝版 PWA 不一定共用原有資料
- PWA 更新可能要在完全關閉舊頁面後才會套用
- 備份匯入會完整覆蓋目前資料，無法合併兩份活動清單
- 工具只根據輸入的 Point 與日期計算，不會連接遊戲帳號或自動讀取遊戲進度

## 建議使用流程

1. 新增手遊名稱
2. 建立活動
3. 每天使用「更新進度」輸入最新 Point
4. 查看剩餘 Point 與每日最低需求
5. 定期匯出 JSON 備份
6. 在活動結束後刪除不再需要的活動

## 技術說明

Event Point Planner 使用原生 HTML、CSS 與 JavaScript 製作，沒有使用前端框架或外部服務。

資料使用瀏覽器 localStorage 保存，離線功能由 Service Worker 提供。
